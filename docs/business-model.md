# PENCIL FORGE 경영 시뮬레이션 · 모델 1

이 문서는 `src/engine/business.ts`의 계산을 설명합니다. 이 앱은 가상 필기구 회사를 운영하는 설계·경영 시뮬레이션입니다. 구매자 수·광고 효율·선호 계수는 수정 가능한 게임 가정이며 실제 시장을 조사해 추정한 판매 예측치가 아닙니다. 기존 제품 조사 자료와 이 시장의 가정은 구분합니다. 모든 통화는 KRW, 가격과 매출은 부가세 제외, 영업손익은 법인세 전입니다.

## 1. 브랜드와 제품의 연결

브랜드 이름·로고·소개를 만들고, 일상/정밀/자연/아틀리에 중 콘셉트를 선택합니다. 라인업마다 주 고객군을 정하며 제품은 정확히 하나의 라인업에 속합니다. 제품은 기존 설계기의 `Project` 전체를 독립 복사해 보관합니다. 소재·형상·그립·버튼·보석을 바꾸면 동일한 메시 적분과 원가 엔진의 질량·제조비가 반영됩니다.

출시한 설계는 UI에서 수정하지 않습니다. 후속 모델 복제로 새 SKU를 만들고 다시 설계·생산합니다. 가격·라인업·생산 수량은 운영 중 조정할 수 있습니다. 초안 삭제와 빈 라인업 삭제를 지원합니다. 최대 8개 라인업·12개 제품입니다.

로고는 워드마크·모노그램·기하 심벌의 파라미터 기반 SVG이며 이름·소개·색상 편집과 SVG 다운로드를 지원합니다. 상표 등록 여부나 명칭의 독점성을 확인한 결과는 아닙니다.

## 2. 원가와 생산

설계기의 원가 계산을 그대로 사용합니다. `estimate({...design, quantity: batch})`의 결과를 `E`, 부품별 수량당 준비비를 `S_i`라 할 때:

```
부담 계수 b = 1 / (1 - 불량률) + 간접비율
재고 단위원가 v = E.unitCost - b × Σ S_i
신규 사출 금형비 = 첫 생산인 경우 b × batch × Σ(사출 부품 S_i), 이후 0
생산 준비비 = b × batch × Σ(사출 이외 부품 S_i), 매 생산에 발생
생산 현금 지출 = batch × v + 신규 사출 금형비 + 생산 준비비
```

사출 금형은 최초 한 번, CNC·프린팅 준비는 생산할 때마다 청구하는 가정입니다. 여러 번 생산한 재고의 장부가는 가중평균 단위원가입니다. 금형·준비비는 해당 달 비용으로 처리하고 재고에 자산화하지 않습니다. 생산 직후 아직 달을 진행하지 않아도 누적손익에는 발생한 준비비가 반영됩니다. 다음 달 손익 장부에 옮겨 적을 때 현금에서 재차 차감하지 않습니다.

생산 자금이 부족하거나 설계 규칙상 오류가 있으면 생산을 거부합니다. 수량은 정수이며 제품당 보관 한도는 100만 개입니다. 소재와 가공 단가는 편집 가정이므로 실제 공급사 견적을 대체하지 않습니다.

## 3. 고객군과 지불 예산

| 고객군 | 월 잠재 구매자 | 기준 가격·예산 중앙값 | 로그 예산 표준편차 σ | 가격탄력성 ε | 경쟁·미구매 가중치 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 학생·일상 | 45,000 | 4,000원 | 0.8 | 1.70 | 3.0 |
| 제도·전문 | 12,000 | 25,000원 | 0.9 | 1.15 | 2.5 |
| 디자인·필기 | 4,000 | 65,000원 | 1.0 | 0.90 | 2.5 |
| 수집·선물 | 180 | 900,000원 | 1.5 | 0.65 | 3.0 |

고객군 s의 예산 B는 `ln(B) ~ Normal(ln(referencePrice_s), σ_s²)`로 가정합니다. 가격 P를 지불할 확률은 `1 - Φ(ln(P/referencePrice_s)/σ_s)`입니다. Φ는 표준정규 누적분포이며 근사 함수의 최대 절대오차는 약 7.5×10⁻⁸입니다. 매월 고객 풀을 새로 형성하며 개별 고객을 계속 추적하지 않습니다.

## 4. 설계 적합도

실제 질량 m(g), 몸통 최대 지름 d(mm), 슬리브 길이 L(mm), 내경 주변 최소 벽 두께 t(mm)를 사용합니다. 아래 지수는 제품 시험 결과나 실제 소비자 평점이 아닙니다.

```
무게 적합도 W = exp[-0.5 × ((m - 선호 질량) / 허용 편차)²]
굵기 적합도 D = exp[-0.5 × ((d - 선호 지름) / 3)²]
정밀 지수 Q = clamp(0.35 + 0.22 × exp[-0.5 × ((L-4)/1.8)²]
               + 0.18 × (심 ≤0.7mm ? 1 : 0.4)
               + 0.12 × (패턴 그립 있음 ? 1 : 0.4)
               + 0.13 × clamp(t/0.6), 0, 1)
공예 지수 C = clamp(0.3 + 소재 계수 + 마감 계수 + 다이아몬드 장식 계수, 0, 1)
```

선호 질량은 순서대로 11/18/16/32g, 선호 지름은 9/9.5/10/10mm입니다. 질량 허용 편차는 12g, 수집 고객군은 28g입니다. 공예 소재 계수는 귀금속 0.40, 목재 0.30, 일반 금속 0.18, 기타 0.05입니다. 폴리싱·오일·투명 코팅 마감은 0.15, 기타는 0.05, 다이아몬드 장식은 0.15입니다.

| 고객군 | W | D | Q | C |
| --- | ---: | ---: | ---: | ---: |
| 학생·일상 | .40 | .35 | .20 | .05 |
| 제도·전문 | .20 | .15 | .60 | .05 |
| 디자인·필기 | .25 | .25 | .10 | .40 |
| 수집·선물 | .10 | .10 | .10 | .70 |

가중합은 0–1의 적합도 F가 됩니다. 몸통 최대 지름에는 볼록함을 포함하고, 최소 벽 두께에는 테이퍼·둥글기·막 두께를 반영합니다. 브랜드 소개 문구를 자연어로 판정해 점수를 만들지는 않습니다.

## 5. 인지도, 선택 확률과 주문

기본 인지도 A=0.04, 평판 R=0.40에서 시작합니다.

```
유효 도달 E = 광고비 / CPM × 1,000 × 유효 도달률
다음 인지도 A' = clamp[A × (1-감쇠율) + (1-A) × (1-exp(-E/총 잠재 구매자))]
제품 매력도 w_i,s = exp[3 × (F_i,s - 0.5) + 0.8 × R]
                    × (기준 가격_s / P_i)^ε_s
                    × 예산 충족 확률 × 라인업 계수 × 콘셉트 계수
선택 확률 p_i,s = w_i,s / (경쟁·미구매 가중치_s + Σ_j w_j,s)
```

라인업의 주 고객군에는 1.2, 다른 고객군에는 0.8을 곱합니다. 브랜드 콘셉트와 고객군이 일치하면 1.12를 추가로 곱합니다. 같은 브랜드의 모든 판매 중 SKU가 분모를 공유하므로 신제품이 기존 제품 수요를 일부 잠식합니다. 인지하지 못한 고객과 경쟁·미구매 선택 모두 이탈 수요입니다. 일시 판매 중지 제품은 선택집합에서 제외합니다.

월 잠재 구매자에는 `1 + 0.12 × sin((월-2)π/6)`의 계절성, `(1+연간성장률)^(경과월/12)`의 성장, `exp(변동성×Z - 변동성²/2)`의 공통 시장 충격을 곱합니다. Z는 표준정규 표본이며 충격은 0.1–5배로 제한합니다.

인지 고객 수를 이항 표본으로 뽑고, 그 수를 위 확률에 따라 순차 조건부 이항 표본으로 배분하여 다항 선택을 구현합니다. 제품당 주문은 재고 이내에서만 처리합니다. 품절 수요는 기회손실로 기록하며 다른 SKU에 다시 배분하지 않습니다. 품절 상품을 판매 중으로 두면 광고와 평판에 불리하므로 판매 중지·추가 생산을 선택할 수 있습니다.

반품은 주문에 대한 이항 표본입니다. 모두 재판매 가능한 상태로 반환된다고 가정합니다. 순판매 = 주문 - 반품, 기말 재고 = 기초 재고 - 순판매입니다.

## 6. 현금과 손익

```
순매출 = 순판매 × 판매가
매출원가 = 순판매 × 재고 장부 단위원가
수수료 = 순매출 × 수수료율
배송·반품비 = 주문 × 배송비 + 반품 × 반품 처리비
영업손익 = 순매출 - 매출원가 - 수수료 - 배송·반품비 - 광고비 - 고정비 - 금형·생산 준비비
판매 현금 변화 = 순매출 - 수수료 - 배송·반품비 - 광고비 - 고정비
누적손익 = 현금 + 재고 자산 - 총 투입 자본
```

생산 시 이미 낸 재고 원가를 판매 현금에서 이중 차감하지 않습니다. 추가 자본은 이익으로 세지 않습니다. 모든 저장·복원 시 현금 장부와 자산·손익 항등식이 맞는지도 검사합니다. 현금이 음수가 된 달은 기록하고 다음 달 진행을 중지합니다. 차입·이자·법인세·부가세·감가상각·도매 외상·납품 지연·중고/불량 반품·설비 생산능력은 모델에 포함하지 않습니다. 준비비는 비용 처리하므로 세무 회계와 다를 수 있습니다.

판매 후 인지도에는 `2 × 순판매 / 고객 풀`에 해당하는 입소문 효과를 지수 형태로 더합니다. 평판은 판매 가중 평균 적합도 S를 향해 `0.15 × (S-R) × 순판매/(순판매+80)`만큼 움직이며 품절 비율×0.015를 차감합니다. 인지도·평판은 항상 0–1입니다.

## 7. 재현성과 불확실성

난수는 상태를 JSON에 보관하는 xorshift32, 정규 표본은 Box–Muller입니다. 이항 분포는 n≤40에서 직접 시행, np<12에서 역누적 계산, 대표본에서는 평균 np·분산 np(1-p)의 정규근사를 사용합니다. 근사값은 정수로 반올림하고 [0,n]으로 제한합니다.

현재 상태에서 80개의 독립 난수 시드를 만들어 다음 한 달을 계산하고 10/50/90 분위수를 표시합니다. 이는 가정한 모델의 시나리오 구간이며 실제 판매의 검증된 신뢰구간이 아닙니다. 시나리오 미리보기는 회사의 실제 난수 상태를 소비하지 않습니다. 같은 모델 버전·경영 JSON·난수 상태는 같은 결과를 만듭니다.

1/3/12개월 진행을 지원하며 중간에 현금 부족에 도달하면 멈춥니다. 자동 재생산은 하지 않습니다. 최근 12회의 생산·월 진행·자본 투입·파일 복원 등을 메모리에서 되돌릴 수 있습니다. 가격·광고·원가 등 조건을 바꾸어 비교할 수 있습니다. 새로고침 후 실행취소 기록은 사라지므로 비교 상태는 경영 JSON으로 보관하세요.

## 8. 저장과 검증

기존 단일 샤프 프로젝트와 별도의 로컬 저장 키를 사용합니다. 경영 JSON에는 브랜드·라인업·제품 전체 설계·모든 가정·재고·현금·월별 기록·난수 상태를 담습니다. CSV에는 월 손익·제품별 판매·생산/증자 현금 거래를 기록합니다. 서버에 실제 상품을 게시하거나 결제를 처리하지 않습니다.

회계 항등식, 원가 엔진 일치, 재고·반품 수량 보존, 가격/경쟁 효과, 같은 브랜드의 수요 잠식, 같은 시드 재현, 불확실성 분위수, 복원 파일 검사, 저자본 생산 거부, 설계 오류 생산 거부, SVG 텍스트 escaping, 120개월 이후 진행·복원를 자동 테스트합니다.
