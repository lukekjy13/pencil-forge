## Included maps

All maps remain 1024 × 1024. Source JPGs were re-encoded with macOS sips for efficient delivery without changing grain, orientation, crop or dimensions.

| Local file | Original file | Interpretation |
| --- | --- | --- |
| `wood-color.jpg` | `Wood051_1K-JPG_Color.jpg` | Albedo, sRGB, JPEG quality 82 |
| `wood-roughness.jpg` | `Wood051_1K-JPG_Roughness.jpg` | Roughness, linear/non-color, JPEG quality 82 |
| `wood-normal.jpg` | `Wood051_1K-JPG_NormalGL.jpg` | OpenGL tangent-space normal, linear/non-color, JPEG quality 88 |

The visible grain runs horizontally in these source images. Rotate the texture when mapping to longitudinal pencil UVs as needed. Do not present this visual approximation as measured material or species data.
